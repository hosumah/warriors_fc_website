# Warriors FC — Version 1

Static, mobile-first Warriors FC website prepared for Cloudflare Pages.

## Deploy
1. Create a GitHub repository and upload these files.
2. In Cloudflare Pages, connect the GitHub repository.
3. Framework preset: None / static HTML. Build command: none. Output directory: `/`.
4. Deploy. Cloudflare will provide a `*.pages.dev` address.
5. Add a custom domain later if desired.

## Replace later
- `assets/warriors-logo.jpeg` with the final high-resolution crest.
- Add team photos to `assets/` and update image paths in `index.html`.
- Replace placeholder squad/next-match content.
- Replace the example contact email.
